# SZU Course Monitor

深圳大学研究生选课“已开课程查询”监控脚本。

这是一个 Tampermonkey 用户脚本，用于定时检查指定课程、指定教学班的容量变化。当目标教学班出现空位或发生扩容时，可以通过浏览器通知、本地声音和 Server酱推送提醒。

## 界面预览

![监控面板](docs/monitor-panel.jpg)

## 功能

- 在“已开课程查询”页面中直接读取你输入的课程号
- 支持一门课程包含多个教学班
- 可在脚本面板中选择只监控某一个教学班
- 每 5 秒自动查询一次
- 监控以下变化：
  - 目标教学班扩容，例如 `62/62 → 62/70`
  - 原本满员后出现空位，例如 `62/62 → 61/62`
  - 已有空位时剩余名额继续增加
- 浏览器通知
- 页面标题闪烁
- 声音提醒
- Server酱消息推送
- 记住不同课程对应的目标教学班
- Server酱 SendKey 只保存在 Tampermonkey 本地存储中，不写入脚本源码

## 安装

1. 安装 Tampermonkey。
2. 确保浏览器允许 Tampermonkey 执行用户脚本。
3. 打开仓库中的 `szu-course-monitor.user.js`。
4. 复制脚本内容，在 Tampermonkey 中新建脚本并保存。

## 使用

1. 登录深圳大学研究生选课系统。
2. 手动进入顶部的“已开课程查询”。
3. 在页面搜索框中输入课程号。
4. 点击一次“查询”，或等待脚本自动查询。
5. 如果该课程存在多个教学班，在右下角监控面板中选择你真正想监控的教学班。
6. 保持页面处于登录状态。

脚本不会自动选课，只做查询与提醒。

## Server酱

点击右下角：

`设置 SendKey`

输入自己的 Server酱 SendKey。

然后点击：

`测试消息推送`

确认手机端可以收到测试消息。

SendKey 通过 Tampermonkey 的 `GM_setValue` 保存在本地，不会上传到本仓库。

## Edge 后台运行建议

为了降低标签页被休眠导致监控暂停的概率，可在 Edge 中打开：

`edge://settings/system`

把：

`https://ehall.szu.edu.cn`

加入“始终使这些网站保持活动状态”。

即使如此，Chromium 对长期后台页面仍可能进行定时器节流，因此 5 秒间隔并不保证在所有后台状态下绝对精确。

## 注意

- 当前默认查询间隔为 5 秒。请合理使用，避免给学校系统造成不必要的请求压力。
- 页面结构或学校接口变化后，脚本可能需要更新。
- 本项目与深圳大学官方无关。
- 请遵守学校选课系统的相关规定。
